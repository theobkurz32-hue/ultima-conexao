# Origem e licenças dos recursos

## Recursos autorais do projeto

| Recurso | Origem | Situação |
| --- | --- | --- |
| `public/assets/coast.svg` | Ilustração vetorial original criada para o projeto. | Distribuída como arte autoral da entrega; não é fotografia real. |
| `public/assets/lighthouse.svg` | Ilustração vetorial original do farol fictício. | Mesma identidade dos demais locais ficcionais. |
| `public/assets/coffee.svg` | Ilustração vetorial original de café. | Sem marca de estabelecimento real. |
| `public/assets/studio.svg` | Ilustração vetorial original de estúdio. | Sem captura de interface de software comercial. |
| `public/assets/ferry.svg` | Ilustração vetorial original de terminal/balsa. | Sem associação a operador real. |
| `public/assets/dunes.svg` | Ilustração vetorial original de dunas. | Sem serviço externo de mapas ou imagens. |
| `public/icon.svg` e PNGs derivados | Ícone original; PNGs gerados por `scripts/generate-icons.mjs`. | Reproduzível localmente com Python + Pillow. |
| Personagens, textos e cidade | Ficção original criada para o projeto. | Não representam mensagens ou dados pessoais reais. |
| `src/utils/sound.ts` | Tom original de interface sintetizado localmente com Web Audio. | Sem gravação externa; inicia apenas após interação. |

As ilustrações são parte final do recorte de fundação, identificado como reconstrução visual. Fotografias narrativas realistas e retratos consistentes ainda não foram produzidos. Não estão sendo substituídos por imagens de bancos aleatórios.

Nenhuma gravação comercial, fotografia de terceiro, marca gráfica de serviço externo ou screenshot de aparelho foi incorporada como interface. Áudio e vídeo narrativos são pendências. Esta relação não concede licença geral ao código do projeto; a escolha de uma licença de distribuição do repositório é uma decisão separada do mantenedor.

Ao adicionar um asset, registrar caminho, autor, fonte verificável, licença e permissão de distribuição antes de publicá-lo. Para composições geradas, conservar instruções e arquivos-fonte necessários à consistência visual. Uma revisão jurídica completa não foi executada nesta entrega.
